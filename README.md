One line roasting a smart fridge: its firmware update takes three hours, two reboots — and it still thinks the milk thrown out on Tuesday is "expiring soon."

## Run it

```sh
node main.ts
```

Writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), after a self-checking gate: 1–200 characters, exactly one line, aimed at the fridge, no obvious grocery-ordering / watching-you angle.
